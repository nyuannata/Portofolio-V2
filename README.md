# 🚀 Yuan Nata Nugraha - AI Engineer & Machine Learning Specialist Portfolio

A modern, high-performance personal portfolio website showcasing AI engineering projects, speech recognition (ASR) pipelines, Retrieval-Augmented Generation (RAG) systems, and machine learning credentials.

Built with **React 18**, **TypeScript**, **Tailwind CSS**, **Vite**, and **shadcn/ui** design architecture.

---

## 🌟 Key Features

- **Iconic Hero Section**: Custom `BlurText` animation for "YUAN NATA", profile picture integration, smooth scroll navigation, and a signature monogram.
- **Dynamic Theme Mode (Dark/Light)**: Seamlessly toggle between dark mode with vibrant neon lime accents (`#C3E41D`) and WCAG AAA-compliant high-contrast light mode (`#365314`).
- **Experience Timeline**: Detailed industry experience at **Astra Credit Companies (ACC)** and **Universitas Sriwijaya**, highlighting OpenAI Whisper Large-v3 (~42GB VRAM GPU), 125 audio annotation benchmarks, Google Gemini RAG, and LLM guardrails.
- **Interactive Projects Showcase**: Categorized filterable project grid (*AI / GenAI*, *Web Application*, *IoT & Hardware*) with accessible popup modals and complete technical feature breakdowns.
- **Competencies & Tech Stack**: Categorized visual bento grid covering AI/ML, PyTorch, Whisper, Gemini API, Python, SQL, React, Firebase, and IoT ESP32.
- **Academics & 8x Dicoding Certifications**: Bachelor's Degree in Computer Systems from Universitas Gunadarma and verified professional certifications in Gen AI, Machine Learning, AWS, and Microsoft Fabric.
- **Reliable Contact & CV Download**: Direct 1-click download of official `CV.pdf`, LinkedIn link, email copy button, and an automated pre-formatted `mailto:` contact form with copy fallback.

## 📦 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/nyuannata/Portofolio-V2.git
cd Portofolio-V2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```
Production assets will be generated in the `dist/` directory.
